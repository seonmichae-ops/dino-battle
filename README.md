# 🦖 공룡 배틀

'뻐끔뻐끔 배틀'을 벤치마킹한 3D 공룡 성장 배틀 게임. 아이와 친구들이 함께 노는 개인 프로젝트.

- 실존 공룡을 실제 시기·고증대로 등장시킴 (예외: 쥐라기 보스 인도미누스 렉스, 영화 크기 랩터)
- 시대 맵: 트라이아스기 → 쥐라기 → 백악기 중기 → 백악기 후기 (앞 시대 Lv.10 달성 시 해금)
- Three.js r128, 빌드 도구 없는 정적 파일 — `index.html`을 그대로 호스팅하면 됨

## 구조
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 마크업 |
| `css/style.css` | 스타일 |
| `js/data.js` | 종·시대·규칙 데이터 |
| `js/engine.js` | 렌더러, 이름표, 지형 |
| `js/models.js` | 절차 생성 공룡 모델 |
| `js/game.js` | 게임 로직, AI, 사운드, UI |
| `tests/` | 헤드리스 브라우저 테스트 (playwright-core) |
